# ATLAS v4.0 — Çok-Ajanlı AI Sistemi

5 farklı LLM modeliyle çalışan, bilimsel makale üretim pipeline'ı.

## Hızlı başlangıç
1. OpenRouter'da API key al
2. OpenCode kur
3. `cp -R .opencode <senin-proje-klasörün>/`
4. `cp opencode.json <senin-proje-klasörün>/`
5. opencode'u aç, `/atlas-faz0` yaz

Detaylı kılavuz: `kullanici-kilavuzu.pdf`
